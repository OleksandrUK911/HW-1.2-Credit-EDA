# Розвідувальний аналіз даних (EDA) про кредитування

Цей проект виконує розвідувальний аналіз даних (EDA) заявок на отримання кредиту, щоб зрозуміти характеристики клієнтів, виявити закономірності та обробити відсутні дані. Аналіз задокументовано в Jupyter Notebook `HW_1_2_Credit_EDA.ipynb`.

## 📋 Огляд

У блокноті аналізується набір даних, що містить інформацію про клієнтів (наприклад, дохід, сума кредиту, освіта, стать), щоб отримати уявлення про кредитний ризик та профілі клієнтів. Він охоплює завантаження даних, очищення, імпутацію пропущених значень та візуалізацію ключових взаємозв'язків.

## 📊 Опис даних

Аналіз базується на файлі `application_data.csv`. Розглянуто ключові стовпці:

-   `SK_ID_CURR`: Унікальний ідентифікатор клієнта.
-   `TARGET`: Цільова змінна (1 - клієнт з труднощами в оплаті, 0 - всі інші випадки).
-   `NAME_CONTRACT_TYPE`: Ідентифікація типу кредиту (готівковий або відновлювальний).
-   `CODE_GENDER`: Стать клієнта.
-   `AMT_CREDIT`: Сума кредиту.
-   `NAME_EDUCATION_TYPE`: Рівень найвищої здобутої освіти клієнта.
-   `OBS_30_CNT_SOCIAL_CIRCLE`: Кількість спостережень соціального оточення клієнта з помітним дефолтом 30 DPD.
-   `EXT_SOURCE_2`: Нормалізований бал із зовнішнього джерела даних.
-   `AMT_GOODS_PRICE`: Для споживчих кредитів це ціна товару, на який видається кредит.

## 🔍 Робочий процес аналізу

Блокнот виконує наступні основні кроки:

1.  **Завантаження даних**: Імпорт бібліотек та читання CSV файлу.
2.  **Початковий огляд**: Перегляд перших рядків (`head()`), перевірка типів даних та описова статистика.
3.  **Обробка відсутніх значень**:
    -   Аналіз стовпців з низьким відсотком пропущених значень (<1%).
    -   **`OBS_30_CNT_SOCIAL_CIRCLE`**: 0.33% пропущено. Заповнено **Медіаною** (0.0), оскільки вона близька до моди та стійка до викидів.
    -   **`EXT_SOURCE_2`**: 0.21% пропущено. Заповнено **Медіаною** (0.57).
    -   **`AMT_GOODS_PRICE`**: 0.09% пропущено. Заповнено **Медіаною** (450,000.0).
4.  **Одноваріантний аналіз**:
    -   Графіки розподілу та ящикові діаграми (boxplots) для розуміння розкиду даних та виявлення викидів.
5.  **Двоваріантний аналіз**:
    -   Аналіз взаємозв'язків між категоріальними та числовими змінними.
    -   Приклад: `NAME_EDUCATION_TYPE` проти `AMT_CREDIT`, сегментовано за `CODE_GENDER`.

## 💡 Ключові висновки

-   **Спостереження соціального оточення**: Більшість клієнтів мають 0 спостережень соціального оточення з дефолтом, але є значні викиди (до 348).
-   **Стратегія імпутації**: Для безперервних змінних з дуже низьким рівнем пропусків (<1%) було обрано імпутацію медіаною, щоб уникнути зміщення через викиди.
-   **Розподіл кредитів**:
    -   Клієнти з "Академічним ступенем" показують широкий діапазон сум кредитів.
    -   Існують чіткі відмінності в сумах кредитів залежно від статі та рівня освіти.
